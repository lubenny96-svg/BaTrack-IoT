# 📦 BaTrack-IoT: Smart Logistics Monitoring System

**BaTrack-IoT** adalah solusi monitoring logistik berbasis IoT yang dirancang untuk meningkatkan keamanan pengiriman barang di wilayah **Batam dan Kepulauan Riau**. Perangkat ini memantau kondisi lingkungan serta mendeteksi benturan fisik secara *real-time*.

## ✨ Fitur Utama
- **Sensing:** Monitoring Suhu & Kelembapan (DHT22) serta Deteksi Guncangan (MPU6050).
- **Data Format:** Menggunakan serialisasi **JSON** untuk integrasi sistem yang efisien.
- **Connectivity:** Mendukung pengiriman data nirkabel.

## 🛠️ Hardware Stack
- **Microcontroller:** ESP32 DevKit V1.
- **Sensors:** DHT22 & MPU6050.
- **Power:** 18650 Li-ion Battery.

## 💻 Software Stack
- **Language:** C++ (Arduino IDE).
- **Format:** JSON.
- **Design:** Figma (UI/UX) & Canva (Business Model Canvas).
